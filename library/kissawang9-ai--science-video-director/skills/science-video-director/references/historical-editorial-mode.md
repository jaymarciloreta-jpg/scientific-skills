# Historical editorial collage mode

Use this mode for history, dynasty, reform, war, institution, historical-economy, and historical-society episodes. Keep the project's first-person protagonist and Q-chibi paper-theatre system. Use original editorial map-and-document grammar without copying Vox branding or visual identity.

## 1. Evidence before drama

Create `historical-evidence-ledger.md` before final narration. Record:

`beat | factual claim | evidence status | source | period/date | evidence object | uncertainty note | reconstruction label`

Use only these evidence statuses:

- `史料确认`: supported by an identified primary or authoritative source;
- `学界推断`: a scholarly interpretation rather than a directly recorded fact;
- `艺术化重现`: invented staging used to make a verified condition visible;
- `存在争议`: meaningful disagreement remains and must not be flattened into certainty.

Prefer archives, museums, official databases, primary documents, academic presses, and current peer-reviewed scholarship. Never invent a quotation, document, boundary, motive, price, title, or casualty number to improve drama.

## 2. Choose the lived viewpoint

Prefer a witness, clerk, merchant, craftsperson, soldier, traveler, worker, or ordinary resident whose decision exposes the mechanism. Use a famous ruler or general only when that person's choice is the causal hinge.

Build the narrative chain as:

`人物处境 → 证据物件 → 地图或制度变化 → 文件证明 → 回到人物代价`

The protagonist must still want something, make a choice, incur a cost, and reinterpret an earlier detail after the reversal.

## 3. Evidence-object grammar

Bind every historical beat to one decisive object:

| Mechanism | Evidence objects | Visible actions |
|---|---|---|
| Power | seal, decree, roster, title plaque, seating order | stamp, cross out, reorder, confiscate |
| Economy | coin, grain sack, tax slip, ledger, scale, price tag | count, weigh, drain, stack, triple |
| War | map, route thread, gate, order, ration cart | advance, close, cut, extinguish, divert |
| Society | household register, contract, ticket, newspaper, work badge | register, deny, queue, tear, exchange |
| Information | letter, notice, rumor slip, printing block | copy, delay, distort, spread, burn |
| Institution | form, permit, boundary marker, checklist | approve, reject, move, seal, split |

The object is evidence, not decoration. Its state must change and produce a consequence for the protagonist.

## 4. One shot, one object, one action

Every shot must answer:

- Who acts?
- What single object carries the fact?
- What one action happens?
- What changed when the shot locks?

Split the shot if it needs several independent actions. Do not use a neutral portrait plus unrelated antique props as historical coverage.

Create `shot-layer-action-map.md` with:

`shot | spoken clause | protagonist | decisive object | main action | background | character state | prop before/after | foreground | entry order/direction | result lock`

Example:

```text
shot: 盐价上涨
spoken clause: 盐价涨了三倍，我却不敢少买
background: market salt stall
character: merchant reaches for the sack, then guards an empty wallet
prop before/after: one-price tag becomes three; coins leave the hand
foreground: waiting buyers close in
entry order: sack drops from top → price flips → coins slide right → character retreats left
result lock: character holds salt while the wallet remains visibly empty
```

## 5. Map as action

Use a map only when geography changes what the protagonist can do.

Valid map actions:

- reveal a route segment by segment;
- move or close a boundary;
- extinguish cities in causal order;
- cut a supply or migration line;
- connect the protagonist's location with the policy center;
- compare before/after reach using the same scale.

Return immediately from the map to a person, document, price, journey, or loss. A static map used as wallpaper does not count as a story beat.

## 6. Period and reconstruction lock

Before generating assets, record:

- date range and location;
- clothing by role and class;
- money, measurement, titles, script, and document form;
- architecture, transport, tools, and materials;
- map source and whether boundaries are exact or schematic;
- paper-aging and palette rules for the episode.

Label a visual as `示意画面` or `艺术化重现` when a reasonable viewer could mistake it for an authentic image or exact reconstruction.

## 7. Asset and motion route

- Generate still images and storyboard masters with the approved image workflow.
- Keep 16:9 and let story density determine the shot count; do not force 45 seconds or nine shots.
- Do not generate Seedance or other image-to-video prompts.
- Crop approved scene cells into independent assets and separate the story-bearing paper layers.
- Translate the layer-action map directly into ChatCut entrances, pose swaps, prop-state changes, parallax, labels, and result locks.
- Add exact Chinese text as editable ChatCut elements.

## 8. Delivery additions

In addition to the standard episode pack, save:

- `historical-evidence-ledger.md`;
- `period-style-lock.md`;
- `shot-layer-action-map.md`;
- a map/source note when geography is used;
- reconstruction labels used in the video and description.

The public description should distinguish verified facts from interpretive or reconstructed scenes without turning into an academic footnote dump.

This mode adapts the transferable public ideas described by YouMind's Vox-style historical material generator: historical objects, map-led explanation, paper-collage visuals, and one-to-one action/element mapping. It deliberately excludes the private prompt, Vox visual identity, fixed 45-second/9-shot structure, vertical format, and Seedance image-to-video output.
